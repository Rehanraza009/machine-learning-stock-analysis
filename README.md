# 📈 Machine Learning Stock Analysis

A full-stack stock analysis application that uses **Machine Learning** to analyze stock market data and generate meaningful insights.

The project is built using **Next.js**, backend APIs, and **Python-based ML scripts**.

---

## 🚀 Features

* 📊 Stock market data analysis
* 🤖 Machine Learning-based insights
* 🌐 Modern frontend using Next.js (App Router)
* 🔌 Backend APIs for data handling
* 🗄️ Database scripts for storage & seeding
* 🎨 Responsive UI with Tailwind CSS

---

## 🛠️ Tech Stack

* **Frontend:** Next.js (App Router), React
* **Styling:** Tailwind CSS
* **Backend:** Node.js (API Routes)
* **Machine Learning:** Python
* **Database:** SQL

## ⚙️ Installation & Setup

```bash id="mlsetup1"
git clone https://github.com/rehanraza009/machine-learning-stock-analysis.git
cd machine-learning-stock-analysis
```

Install dependencies:

```bash id="mlsetup2"
npm install
```

Run the development server:

```bash id="mlsetup3"
npm run dev
```
